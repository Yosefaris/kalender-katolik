# Versi Apps Script (arsip)

File di folder ini adalah versi Google Apps Script dari Belajar Ceria (BC-V4.2).

- `Code.gs` — hanya menyajikan `Index.html` (fungsi `doGet`).
- `Index.html` versi web app-nya ada di `www/index.html` (file yang sama dipakai APK).

Cara pakai: buat proyek Apps Script baru, buat file `Code.gs` dan `Index.html`,
tempel isinya, lalu Deploy sebagai web app.

Catatan: APK Android tidak memakai file ini — aplikasi di HP membuka
`www/index.html` langsung, tanpa server.
