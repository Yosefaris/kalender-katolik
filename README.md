# Kalender Katolik

Aplikasi kalender Katolik (November 2026–Desember 2027): santo/santa harian,
bacaan Misa lengkap 365 hari tahun 2027, riwayat 267 Paus, dan Alkitab AYT
lengkap (66 kitab, 31.102 ayat) dengan pencarian teks penuh.

Dibangun dengan Capacitor (WebView) dari `www/` (index.html + paus-data.js +
alkitab-ayt.js). Versi web live di https://kalender-katolik.vercel.app.

APK debug dibangun otomatis oleh GitHub Actions
(`.github/workflows/build-apk.yml`) dan tersedia sebagai artifact
`Kalender-Katolik-debug`, sekaligus diterbitkan ke Release `v1.0.0`.
